Implement a public API named `ST_S2ToGeom` that accepts a collection of S2 cell identifiers and returns a collection of polygon geometries representing each cell. The function must be callable from Java code (e.g., `Functions.s2ToGeom(long[] cellIds)`) and exposed as a SQL function in Flink, Spark, and the Python DataFrame API. For any input array, the output array must preserve the original order of cell IDs. Each returned polygon must intersect the source geometry from which the cell IDs were derived, which is verified by checking intersections at specific indices (0, 20, and 100). The resulting array must be compatible with the existing `ST_Collect` function, producing a geometry of type `MULTIPOLYGON` when aggregated. The function should handle inputs provided as a primitive long array, a boxed `Long[]` array, a Spark column expression, a Flink table expression, or a Python list/column, and always return an array of Sedona `Geometry` objects that can be used in subsequent spatial operations such as `ST_Intersects`.
