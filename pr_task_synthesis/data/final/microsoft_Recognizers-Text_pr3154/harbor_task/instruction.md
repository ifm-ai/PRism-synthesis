The Spanish language recognizer currently fails to extract date ranges that refer to a decade when the wording uses the word "años" or "anos" (with or without the tilde) and when the decade is expressed together with a century number. It also does not recognise age expressions that contain the word "anos" without the accent. The required behavior is that the recognizer should correctly identify and resolve these patterns regardless of the presence of diacritics. For example, phrases such as "escrito en los años 90", "los años setenta", "¿Cuáles fueron los presidentes de Estados Unidos en la década de 1990?", and "Tengo diez anos" must be parsed successfully. The decade expressions should be resolved to a ten‑year date range (e.g., "años 90" → 1990‑01‑01 to 2000‑01‑01, "década de 1990" → the same range) and the age expressions should be resolved to a numeric value with the unit "Año" (e.g., "diez anos" → value 10, unit Año). The recognizer must treat both accented and unaccented forms of "año"/"años"/"ano" and the "ñ" character in "año" as equivalent, handling singular and plural forms, and should work consistently across all public parsing APIs that expose date‑time and number‑with‑unit results.

The implementation should update the Spanish language patterns so that they match the words "año", "anos", "años" and their plural forms when they appear as date units or age units. The updated patterns must not interfere with existing functionality for other units or date expressions. The change should be observable through the library's standard output structures: a date‑time result of type "daterange" with a TIMEX expression representing the decade, and an age result of type "age" with a numeric value and the unit "Año". All other aspects of the recognizer's behavior should remain unchanged.
