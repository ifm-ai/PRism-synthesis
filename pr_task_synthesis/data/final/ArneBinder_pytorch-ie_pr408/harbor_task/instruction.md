Implement ordering for any subclass of the core `Annotation` class so that Python's built‑in sorting functions (e.g., `sorted`) can arrange collections of annotations deterministically. The ordering must consider only dataclass fields whose `compare` flag is true, following the declaration order of those fields, and must completely ignore any internal bookkeeping attribute named `_targets`. When two annotation instances are compared, their sets of comparable field names must be identical; if they differ, the comparison should raise a `ValueError` whose message exactly matches `"comparison field names do not match: ['a', 'n'] != ['a', 'b', 'c']"`. The comparison must be recursive: if a comparable field is itself an `Annotation` instance, its own ordering logic should be invoked to determine the relative order. With these rules, a list of simple annotation objects (e.g., with integer fields `a`, `b`, `c`) should sort lexicographically by the comparable fields, ignoring optional fields that are equal across instances. A list containing nested annotation objects should sort first by the outer comparable fields and then by the inner annotation's ordering. Attempting to sort a heterogeneous list of annotations that have different comparable field sets must raise the specified `ValueError`. The solution must integrate seamlessly with Python's sorting mechanisms without requiring callers to invoke any special methods.
