When a Conditional formatting rule is added to a worksheet, the Xlsx writer later queries the Conditional object for any associated text via its getText() method. If the Conditional instance has never had its text explicitly set, the internal text field is uninitialized, causing PHP to raise a typed error when getText() is called. The required behavior is that a newly created Conditional object must have its text field initialized to an empty string so that getText() always returns a string value, even when no text has been provided. With this change, creating a Conditional, configuring its type to CONTAINSTEXT, setting an operator of type OPERATOR_CONTAINSTEXT, applying a style, and attaching it to a cell range (e.g., "C3:E5") must not throw any exception during the Xlsx writing process. The Xlsx writer's Worksheet::writeWorksheet method should produce XML that includes the element `<conditionalFormatting sqref="C3:E5">`, confirming that the conditional rule was processed successfully. No other functionality of the Conditional class should be altered; existing getters, setters, and validation must continue to operate as before.
